¿Cómo valida Minka una imagen legal?

Cuando un abogado sube una imagen, ¿qué debe verificar el sistema?

Criterios de rechazo — ¿cuáles aplican?

A

Ilegible / baja calidad

Foto borrosa, oscura, torcida o con texto irreconocible. Claude no puede extraer datos útiles.

B

No es un documento legal

Foto de comida, selfie, paisaje. No tiene relación con un caso legal peruano.

C

Sin texto extraíble

La imagen no contiene texto suficiente para pre-llenar ningún campo del caso.

D

Formato no soportado

Solo aceptar JPG, PNG, WEBP — rechazar HEIC, BMP, TIFF, etc.

¿Qué pasa si la imagen pasa validación pero extrae pocos campos?

1

Aceptar con advertencia

Mostrar qué campos se pudieron extraer y cuáles debe completar el abogado manualmente

2

Rechazar si extrae menos de X campos

Mínimo de campos requeridos (ej: nombre_cliente + tipo_caso) para aceptar el documento
